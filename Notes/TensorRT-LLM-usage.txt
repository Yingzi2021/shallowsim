Usage: trtllm-serve serve [OPTIONS] MODEL

  Running an OpenAI API compatible server

  MODEL: model name | HF checkpoint path | TensorRT engine path

Options:
  --tokenizer TEXT                Path | Name of the tokenizer.Specify this
                                  value only if using TensorRT engine as
                                  model.
  --host TEXT                     Hostname of the server.
  --port INTEGER                  Port of the server.
  --backend [pytorch]             Set to 'pytorch' for pytorch path. Default
                                  is cpp path.
  --log_level [internal_error|error|warning|info|verbose|debug]
                                  The logging level.
  --max_beam_width INTEGER        Maximum number of beams for beam search
                                  decoding.
  --max_batch_size INTEGER        Maximum number of requests that the engine
                                  can schedule.
  --max_num_tokens INTEGER        Maximum number of batched input tokens after
                                  padding is removed in each batch.
  --max_seq_len INTEGER           Maximum total length of one request,
                                  including prompt and outputs. If
                                  unspecified, the value is deduced from the
                                  model config.
  --tp_size INTEGER               Tensor parallelism size.
  --pp_size INTEGER               Pipeline parallelism size.
  --ep_size INTEGER               expert parallelism size
  --cluster_size INTEGER          expert cluster parallelism size
  --gpus_per_node INTEGER         Number of GPUs per node. Default to None,
                                  and it will be detected automatically.
  --kv_cache_free_gpu_memory_fraction FLOAT
                                  Free GPU memory fraction reserved for KV
                                  Cache, after allocating model weights and
                                  buffers.
  --num_postprocess_workers INTEGER
                                  [Experimental] Number of workers to
                                  postprocess raw responses to comply with
                                  OpenAI protocol.
  --trust_remote_code             Flag for HF transformers.
  --extra_llm_api_options TEXT    Path to a YAML file that overwrites the
                                  parameters specified by trtllm-serve.
  --reasoning_parser [deepseek-r1]
                                  [Experimental] Specify the parser for
                                  reasoning models.
  --help                          Show this message and exit.
